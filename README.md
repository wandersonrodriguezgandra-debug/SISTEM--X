# Safety and Health at Work (SST) Integrated Management System

## Project Objectives
The objective of the SST integrated management system is to provide a comprehensive platform that improves the safety and health conditions in the workplace. This system aims to facilitate compliance with regulatory requirements, enhance risk management, and promote a safety culture among employees.

## Modules
1. **Risk Management**: Identify, assess, and mitigate workplace hazards.
2. **Incident Reporting**: Allow employees to report safety incidents and near misses easily.
3. **Training Management**: Track and manage safety training for employees.
4. **Compliance Monitoring**: Ensure adherence to safety regulations and standards.
5. **Audit Management**: Conduct safety audits and inspections to continuously improve workplace safety.

## Technology Stack
- **Frontend**: React.js for building user interfaces.
- **Backend**: Node.js with Express for server-side development.
- **Database**: MongoDB for data storage.
- **Authentication**: JSON Web Tokens (JWT) for user authentication.
- **Hosting**: Heroku for deploying the application.

## Installation Instructions
1. Clone the repository:
   ```bash
   git clone https://github.com/wandersonrodriguezgandra-debug/SISTEM--X.git
   ```
2. Navigate to the project directory:
   ```bash
   cd SISTEM--X
   ```
3. Install the required dependencies:
   ```bash
   npm install
   ```
4. Create a `.env` file in the root directory and configure your environment variables as needed.
5. Run the application:
   ```bash
   npm start
   ```
6. Access the application at `http://localhost:3000`.
